# Python - Exception Handling

This directory contains projects and exercises focused on Python runtime error management.

## Project Files
- `safe_print_list.py`: Prints `x` elements of a list safely without using `len()`.
- `safe_print_integer.py`: Prints an integer safely using `"{:d}".format()`.
- `safe_print_list_integers.py`: Prints integer elements up to `x`.
- `safe_print_division.py`: Divides two numbers safely with a `finally` block.
- `raise_exception.py`: Explicitly raises a `TypeError`.
- `raise_exception_msg.py`: Raises a `NameError` with a custom message.
